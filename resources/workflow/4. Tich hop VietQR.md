### **2\. Chuẩn Dữ Liệu Mã QR (EMVCo VietQR Specification)**

Mã VietQR động được tạo dựa trên tiêu chuẩn EMVCo với các thông tin cốt lõi:

* **Payload Format Indicator:** 00 (Giá trị: 01\)  
* **Point of Initiation Method:** 12 (QR động \- Dynamic QR)  
* **Merchant Account Information (NAPAS 247):** BIN ngân hàng \+ Số tài khoản nhận tiền.  
* **Transaction Amount (Tag 54):** Số tiền cần thanh toán chính xác theo hóa đơn.  
* **Additional Data Field (Tag 62 / Nội dung chuyển khoản):** Mã hóa đơn (Ví dụ: NINOPOS100234).

### **3\. Chi Tiết API Integration**

#### **A. API Sinh Mã VietQR Động (Tạo tại Local/Server)**

**Endpoint:** POST /api/v1/payments/vietqr/generate  
**Headers:** Content-Type: application/json, Authorization: Bearer \<API\_KEY\>

* **Request Payload (JSON):**

JSON  
{  
  "accountNo": "0123456789",  
  "accountName": "CONG TY TNHH CONG NGHE & DICH VU NINOTEK",  
  "acqId": "970436",   
  "amount": 150000,  
  "addInfo": "NINOPOS100234",  
  "format": "text",  
  "template": "compact"  
}

*(Ghi chú acqId: Mã BIN Ngân hàng, ví dụ 970436 là Vietcombank, 970415 là VietinBank...)*

* **Response (JSON):**

JSON  
{  
  "code": "00",  
  "desc": "Thành công",  
  "data": {  
    "qrCode": "00020101021238570010A00000072701270006970436011001234567890208QRIBFTTA530370454061500005802VN62170813NINOPOS1002346304A1B2",  
    "qrDataURL": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."  
  }  
}

#### **B. API Nhận Webhook Thông Báo Chuyển Khoản Thành Công (IPN Callback)**

Khi khách hàng hoàn tất chuyển khoản qua ứng dụng Ngân hàng/Ví điện tử, Cloud Backend của Ninotek sẽ nhận Webhook từ Cổng thanh toán / Ngân hàng / Casso / SePAY để xác thực.  
**Endpoint:** POST /api/v1/payments/vietqr/webhook  
**Headers:** X-Signature: \<HMAC\_SHA256\_HASH\>

* **Webhook Payload (JSON):**

JSON  
{  
  "gateway": "VietQR\_Baokim",  
  "transaction\_id": "FT2624490182",  
  "amount": 150000,  
  "content": "NINOPOS100234 CHUYEN KHOAN",  
  "order\_id": "NINOPOS100234",  
  "bank\_account": "0123456789",  
  "status": "SUCCESS",  
  "timestamp": "2026-09-01T13:17:08+07:00"  
}

### **4\. Tích Hợp Real-time Xác Nhận Thanh Toán (WebSocket)**

Để máy POS thu ngân **NinoPOS** nhận ngay thông báo mà không cần bấm "Xác nhận thủ công":

> 1. **Khởi tạo kết nối WebSocket trên NinoPOS:**  
   * **URL:** ws://localhost:8080/ws/payments?order\_id=NINOPOS100234  
> 2. **Nhận sự kiện tự động đóng Bill:**

JSON  
{  
  "event": "PAYMENT\_SUCCESS",  
  "order\_id": "NINOPOS100234",  
  "payment\_method": "VIETQR",  
  "amount\_paid": 150000,  
  "message": "Thanh toán VietQR thành công"  
}

> 3. **Thao tác tự động của máy POS:**  
   * Màn hình POS chuyển sang trạng thái "Đã thanh toán".  
   * Kích hoạt lệnh in hóa đơn tự động ra máy in nhiệt (Khổ 80mm/58mm).  
   * Đẩy dữ liệu giao dịch lên **NinoDash** cho chủ quản lý.
