Đối với hệ thống phần mềm **Ninotek POS** (gồm 3 module **NinoPOS** trên Windows, **NinoOrder** và **NinoDash** trên Mobile/Tablet), chiến lược đóng gói và quản lý bản quyền (License Management) đóng vai trò then chốt để bảo vệ tài sản trí tuệ và tạo doanh thu bền vững.

### **1\. Chiến Lược Đóng Gói Ứng Dụng (Packaging & Deployment)**

**A. Module NinoPOS (Windows Desktop)**

* **Công nghệ đóng gói:** Sử dụng **Inno Setup** hoặc **Advanced Installer** để tạo duy nhất 1 file cài đặt .exe hoặc .msi.  
* **Thành phần đi kèm trong bộ cài:**  
  * Tự động cài đặt/kiểm tra **.NET Runtime** hoặc **Node.js Environment** phụ thuộc.  
  * Tự động khởi tạo và cấu hình cơ sở dữ liệu local (**SQLite** hoặc **PostgreSQL Local**) ẩn bên dưới.  
  * Tích hợp sẵn Service chạy ngầm (**Windows Service**) đảm nhận nhiệm vụ đồng bộ dữ liệu sync\_queue lên Cloud khi có mạng.  
* **Cập nhật tự động (Auto-Update):** Sử dụng thư viện **AutoUpdater.NET** để kiểm tra phiên bản mới mỗi khi khởi động app và cho phép nâng cấp 1-click.

**B. Module NinoOrder & NinoDash (Android / iOS)**

* **Phân phối chính thức:** Đóng gói file .apk / .aab cho **Google Play Store** và .ipa cho **Apple App Store**.  
* **Phân phối nội bộ (Cho khách hàng doanh nghiệp/chuỗi):** Với các quán muốn cài riêng trên máy POS cầm tay Android (như Sunmi, PAX, iMin), xuất file **APK trực tiếp** để cài bằng tay hoặc quản lý qua hệ thống **MDM (Mobile Device Management)**.

### **2\. Mô Hình Quản Lý Bản Quyền & Giấy Phép (Licensing Model)**

Để kinh doanh hiệu quả, Ninotek nên áp dụng mô hình cấp phép **Hybrid SaaS / Serial Key Active**:  
**A. Cơ Chế Active Bản Quyền (License Key System)**

> 1. **Machine Fingerprint (Mã phần cứng):** Khi cài **NinoPOS** lên máy Windows, ứng dụng tự động lấy chuỗi băm duy nhất từ CPU ID \+ Motherboard Serial \+ MAC Address (Machine\_Code).  
> 2. **Kích hoạt (Activation):** Khách hàng nhập **License Key** (do Ninotek cấp). App gửi Machine\_Code \+ License Key lên Cloud Server của Ninotek để xác thực.  
> 3. **Khóa thiết bị:** 1 License Key chỉ cho phép kích hoạt đúng số lượng máy trạm POS đã mua.

**B. Các Gói Cước Kinh Doanh**

* **Gói Trả Phí Định Kỳ (SaaS Subscriptions \- Đề xuất):** Thu phí theo Tháng/Năm.  
  * Nếu hết hạn thuê bao mà chưa gia hạn, app **NinoPOS** vẫn cho phép bán hàng offline nhưng chặn tính năng đồng bộ lên **NinoDash** và tính năng VietQR tự động.  
* **Gói Bán Vĩnh Viễn (Lifetime License):** Bán bản quyền xài trọn đời cho máy Windows local \+ tặng kèm 1 năm Cloud Reporting. Sau 1 năm, nếu muốn dùng app xem báo cáo trên điện thoại thì đóng thêm phí Cloud theo năm.

### **3\. Bảo Vệ Bản Quyền Code (Anti-Decompile & Security)**

Để tránh bị đối thủ hoặc thợ kỹ thuật "crack" hay reverse engineering (đọc ngược mã nguồn):

* **Bảo vệ Code C\# (.NET) trên Windows:** Sử dụng các công cụ Obfuscator hàng đầu như **ConfuserEx**, **Dotfuscator** hoặc **Obfuscator.NET** để làm rối mã nguồn, mã hóa chuỗi API Key và bảo vệ logic thuật toán.  
* **Bảo vệ Mobile App (Flutter):** Sử dụng tính năng obfuscate mặc định khi build bản Production:  
  Bash  
  flutter build apk \--obfuscate \--split-debug-info=/symbols

* **Bảo vệ API & Webhook:** Tất cả các giao tiếp API giữa máy POS và Cloud đều phải được mã hóa qua **HTTPS/TLS**, sử dụng **JWT (JSON Web Token)** ngắn hạn và xác thực chữ ký số **HMAC-SHA256** cho từng giao dịch.
