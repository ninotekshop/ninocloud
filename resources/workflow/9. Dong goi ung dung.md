Dưới đây là file cấu hình kịch bản chi tiết (NinoPOS\_Setup.iss) dành cho **Inno Setup**. File này đã được tối ưu để đóng gói ứng dụng **NinoPOS** trên Windows, tự động kiểm tra môi trường, tạo lối tắt (shortcut), cấp quyền Admin và đăng ký thông tin gỡ cài đặt chuyên nghiệp.

### **Các Điểm Cấu Hình Quan Trọng**

* **AppId:** Chuỗi GUID cố định duy nhất. Giúp Windows nhận biết đúng bản cập nhật/đè phiên bản cũ khi bạn phát hành các bản patch sau này.  
* **ArchitecturesInstallIn64BitMode=x64:** Ép bộ cài đặt hoạt động theo chuẩn 64-bit tối ưu hiệu năng cho máy POS Windows hiện đại.  
* **Compression=lzma2/ultra64:** Chuẩn nén cao nhất giúp thu nhỏ tối đa dung lượng file .exe đầu ra để Sales dễ gửi qua Zalo/Email cho khách hàng.  
* **PrivilegesRequired=admin:** Đảm bảo bộ cài có đủ quyền tạo thư mục trong C:\\Program Files và đăng ký Windows Service kết nối máy in/két tiền qua giao thức LAN/USB.

### **Hướng Dẫn Sử Dụng Để Tạo File Setup**

> 1. Tải và cài đặt phần mềm [Inno Setup Compiler](https://jrsoftware.org/isdl.php).  
> 2. Đặt file icon NinoPOS\_Icon.ico vào thư mục assets/ và trỏ đường dẫn file đã publish (C\# / Electron / C++) vào mục \[Files\].  
> 3. Mở file NinoPOS\_Setup.iss bằng Inno Setup và nhấn **Build ➔ Compile** (hoặc phím tắt Ctrl \+ F9).  
> 4. File cài đặt hoàn chỉnh NinoPOS\_Setup\_v1.0.0.exe sẽ được tạo ra trong thư mục Output/.
