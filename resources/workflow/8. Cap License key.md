Dưới đây là thiết kế chi tiết về **Cơ chế & Thuật toán cấp phát License Key** bảo mật cho bộ phận Sales của Ninotek, bao gồm cấu trúc mã Key, giải thuật mã hóa không đối xứng (RSA/Ed25519) và script Python công cụ dành cho Sales.

### **1\. Kiến Trúc Bảo Mật License Key**

Để tránh bị rò rỉ Key hoặc bị làm giả Key từ phía khách hàng (crack), Ninotek áp dụng cơ chế **Mã hóa chữ ký số không đối xứng (Asymmetric Digital Signature)**:

* **Sales Tool (Server / Private Key):** Bộ phận Sales giữ **Private Key** bảo mật trên Server Ninotek. Khi có đơn hàng, Server dùng Private Key để "ký" lên thông tin khách hàng (Mã máy, Ngày hết hạn, Loại gói cước) và tạo ra **License Key**.  
* **NinoPOS App (Client / Public Key):** Ứng dụng **NinoPOS** chỉ nhúng **Public Key**. App giải mã License Key bằng Public Key và so sánh với thông tin phần cứng local. Do không chứa Private Key, hacker không thể mã hóa ngược để tự tạo Key giả.

### **2\. Cấu Trúc Dữ Liệu Bên Trong License Key**

Một chuỗi License Key đóng gói các dữ liệu cốt lõi sau:

* machine\_id: Mã phần cứng duy nhất của máy POS Windows (Mainboard ID \+ CPU Serial \+ MAC Address).  
* package\_type: Gói cước (BASIC, PRO, ENTERPRISE).  
* expiry\_date: Ngày hết hạn bản quyền (Định dạng YYYY-MM-DD).  
* max\_devices: Số lượng máy order (NinoOrder) tối đa được kết nối LAN.  
* signature: Chữ ký số mã hóa bằng Private Key để chống sửa đổi dữ liệu.

### **3\. Thuật Toán Python License Generator (Cho Sales)**

Bộ phận Sales sử dụng script Python này (hoặc tích hợp vào trang Web Admin quản lý Khách hàng của Ninotek) để cấp Key:

Python  
import base64  
import json  
from datetime import datetime  
from cryptography.hazmat.primitives import hashes, serialization  
from cryptography.hazmat.primitives.asymmetric import padding, rsa

\# 1\. Khởi tạo / Load Cặp khóa RSA (Chạy 1 lần trên Server Sales)  
def generate\_key\_pair():  
    private\_key \= rsa.generate\_private\_key(  
        public\_exponent=65537,  
        key\_size=2048  
    )  
    return private\_key, private\_key.public\_key()

\# 2\. Hàm Sales tạo License Key  
def create\_license\_key(private\_key, machine\_id, package\_type, expiry\_date, max\_devices=3):  
    \# Đóng gói Payload  
    payload \= {  
        "mid": machine\_id,  
        "pkg": package\_type,  
        "exp": expiry\_date,  
        "dev": max\_devices,  
        "gen": datetime.now().strftime("%Y-%m-%d")  
    }  
      
    \# Chuyển payload thành JSON String  
    payload\_json \= json.dumps(payload, separators=(',', ':'))  
      
    \# Tạo chữ ký số (Digital Signature) bằng Private Key  
    signature \= private\_key.sign(  
        payload\_json.encode('utf-8'),  
        padding.PSS(  
            mgf=padding.MGF1(hashes.SHA256()),  
            salt\_length=padding.PSS.MAX\_LENGTH  
        ),  
        hashes.SHA256()  
    )  
      
    \# Đóng gói Data \+ Signature thành chuỗi Base64 hoàn chỉnh  
    full\_license \= {  
        "data": payload\_json,  
        "sig": base64.b64encode(signature).decode('utf-8')  
    }  
      
    raw\_license\_bytes \= json.dumps(full\_license).encode('utf-8')  
    license\_key\_b64 \= base64.b64encode(raw\_license\_bytes).decode('utf-8')  
      
    \# Format dạng nhóm 5 ký tự dễ nhìn cho Sales copy (Ví dụ: NINO-XXXXX-XXXXX-...)  
    return "NINO-" \+ "-".join(\[license\_key\_b64\[i:i+5\] for i in range(0, len(license\_key\_b64), 5)\])

\# \--- VÍ DỤ CHẠY THỰC TẾ CHO SALES \---  
if \_\_name\_\_ \== "\_\_main\_\_":  
    priv\_key, pub\_key \= generate\_key\_pair()  
      
    \# Mã máy lấy từ máy POS Windows của khách hàng  
    client\_machine\_id \= "BFEBFBFF000906EA-A0369F2C"   
      
    \# Sales cấp gói PRO, thời hạn 1 năm  
    license\_key \= create\_license\_key(  
        private\_key=priv\_key,  
        machine\_id=client\_machine\_id,  
        package\_type="PRO",  
        expiry\_date="2027-09-01",  
        max\_devices=5  
    )  
      
    print("=== NINO LICENSE KEY CẤP CHO KHÁCH HÀNG \===")  
    print(license\_key)

### **4\. Thuật Toán Xác Thực Key Trực Tiếp Trực Tiếp Trên NinoPOS (.NET/C\#)**

Tại ứng dụng **NinoPOS trên Windows**, hệ thống dùng **Public Key** giải mã và đối soát:

> 1. **Format lại chuỗi Key:** Gỡ bỏ tiền tố NINO- và gộp chuỗi Base64 ban đầu.  
> 2. **Xác thực chữ ký số:** Dùng Public Key kiểm tra xem sig có khớp đúng với data không. Nếu không khớp ➔ Key bị can thiệp/làm giả.  
> 3. **Kiểm tra Mã máy (mid):** Lấy Fingerprint cứng của máy Windows hiện tại, so sánh với mid. Nếu không trùng ➔ Key bị sao chép sang máy khác.  
> 4. **Kiểm tra Ngày hết hạn (exp):** So sánh với ngày hệ thống \+ ngày đồng bộ Server gần nhất (để chống khách hàng tự lùi giờ Windows).
