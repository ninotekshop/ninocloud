Dưới đây là thiết kế chi tiết về Luồng dữ liệu (Data Flow), Kiến trúc API và Định hướng UI/UX Wireframe cho cả 3 module (**NinoPOS**, **NinoOrder**, **NinoDash**) theo chuẩn bộ nhận diện thương hiệu Ninotek.  
**1\. Luồng Dữ Liệu Tổng Thể (Data Flow Architecture)**  
Hệ thống hoạt động theo cơ chế **Hybrid Offline-First / Local-LAN First** kết hợp **Cloud Real-time Sync** để đảm bảo tốc độ tối đa tại quán và cập nhật tức thì cho quản lý.

* **Luồng Order & Báo Bếp (NinoOrder ➔ NinoPOS ➔ KDS/Printer):**  
  * Nhân viên dùng **NinoOrder** chọn bàn ➔ Tạo order.  
  * Dữ liệu gửi trực tiếp qua mạng **LAN nội bộ (WebSocket / gRPC)** tới trạm thu ngân **NinoPOS** (Độ trễ \< 0.5s).  
  * **NinoPOS** lưu SQLite/PostgreSQL nội bộ và tự động kích hoạt lệnh in xuống máy in bếp (LAN/USB) hoặc màn hình KDS.  
* **Luồng Thanh Toán & Đồng Bộ Cloud (NinoPOS ➔ Cloud Server ➔ NinoDash):**  
  * Thu ngân chốt đơn trên **NinoPOS** ➔ Sinh mã **VietQR động** ➔ Khách quét và thanh toán.  
  * Khi giao dịch hoàn tất, **NinoPOS** trừ kho định lượng nguyên liệu nội bộ và đẩy dữ liệu giao dịch lên **Cloud Backend (Node.js/Go API)**.  
  * **Cloud Backend** phát sự kiện **Push Notification / Real-time Event** xuống ứng dụng **NinoDash** của chủ quán.

**2\. Kiến Trúc API Cốt Lõi (RESTful & WebSocket)**  
**A. Local LAN API (NinoOrder ↔ NinoPOS trên Windows)**

* POST /api/v1/lan/order/create: Gửi danh sách món, ghi chú topping và ID bàn từ NinoOrder về POS.  
* GET /api/v1/lan/tables/status: Lấy sơ đồ bàn real-time (Trống, Đang ăn, Chờ thanh toán).  
* WS /ws/lan/kitchen: Kênh WebSocket nhận tín hiệu cập nhật trạng thái món (Chờ làm, Đang làm, Đã xong).

**B. Cloud API (NinoPOS / NinoDash ↔ Cloud Backend)**

* POST /api/v1/cloud/sync/transactions: Đồng bộ hóa đơn và dữ liệu doanh thu lên Server.  
* GET /api/v1/cloud/reports/dashboard: Lấy chỉ số tổng quan (Doanh thu, số lượt khách, best-seller) cho NinoDash.  
* POST /api/v1/cloud/payments/vietqr/generate: Sinh VietQR động từ cổng thanh toán.  
* WS /ws/cloud/realtime-reports: Kênh WebSocket nhảy doanh thu và báo cáo thời gian thực trên NinoDash.

**3\. Khung Thiết Kế UI/UX Wireframe Theo Chuẩn Ninotek**  
**A. Quy Chuẩn Màu Sắc & Typography**

* **Primary Color:** Xanh Blue Gradient (\#007AFF ➔ \#0055FF) – Tạo cảm giác hiện đại, chuẩn công nghệ.  
* **Accent Colors:** Xanh lá (\#34C759 \- Bàn trống/Hoàn tất), Cam (\#FF9500 \- Đang chế biến), Đỏ (\#FF3B30 \- Cảnh báo kho/Bàn chờ trả tiền).  
* **Font chữ:** Inter hoặc Segoe UI (rõ ràng, dễ đọc trên màn hình cảm ứng).

**B. UI/UX Wireframe Module 1: NinoPOS (Windows Desktop \- Màn cảm ứng 15-19 inch)**

* **Layout 3 Cột:**  
  * **Cột trái (20%):** Danh mục món (Cà phê, Trà sữa, Món nhậu, Đồ uống) & Thanh chuyển tab (Sơ đồ bàn / Bán nhanh / Két tiền).  
  * **Cột giữa (55%):** Sơ đồ bàn visual (dạng lưới grid) hoặc Menu danh sách món có hình ảnh đại diện lớn, bấm chạm mượt mà.  
  * **Cột phải (25%):** Chi tiết hóa đơn hiện tại (Món đã chọn, topping, tổng tiền, nút bấm **Tạo VietQR**, **Thanh toán**, **In bill**).

**C. UI/UX Wireframe Module 2: NinoOrder (Mobile / Tablet \- Android & iOS)**

* **Layout dạng Thẻ (Card-based UI):**  
  * **Màn hình Sơ đồ bàn:** Phân loại theo Tầng/Khu vực. Thẻ bàn hiển thị số người, thời gian ngồi và tổng tiền tạm tính.  
  * **Màn hình Chọn món:** Ô tìm kiếm nhanh \+ danh mục món dạng Tab vuốt ngang.  
  * **Popup Customization:** Hiện nhanh bảng chọn Topping, tỷ lệ Đường/Đá, Ghi chú đặc biệt (không cay, ít hành).  
  * **Thanh Bottom Bar:** Hiển thị tổng số món đã chọn & Nút "Gửi Bếp" nổi bật màu xanh Ninotek.

**D. UI/UX Wireframe Module 3: NinoDash (Mobile App cho Chủ quán)**

* **Layout Dashboard Tổng Quan:**  
  * **Header:** Logo NinoDash \+ Chọn chi nhánh/Cửa hàng \+ Bộ lọc thời gian (Hôm nay, Hôm qua, Tháng này).  
  * **Card Doanh Thu Real-time:** Số tiền lớn nổi bật, có biểu thị % tăng/giảm so với ngày trước.  
  * **Biểu đồ Tương tác (Charts):** Biểu đồ đường (Line chart) doanh thu theo giờ trong ngày; Biểu đồ cột (Bar chart) Top 5 món bán chạy nhất.  
  * **Cảnh báo Thông minh:** Khối thông báo đỏ hiện cảnh báo lãng phí, nguyên vật liệu sắp hết hoặc ca làm việc có thao tác hủy món nghi vấn.
